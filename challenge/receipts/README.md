# Public challenge receipts

`index.json` is the machine-readable registry for public challenge lifecycle visibility.

A receipt is not a substantive judgment. It records only the public intake binding and
current process state defined by `../LIFECYCLE-CONTRACT.md`.

The registry intentionally permits unresolved `RECEIVED`, `MECHANICALLY_VALID`, and
`UNDER_REVIEW` records without inventing an adjudication deadline. Their timestamps make
their age observable.

Confidential security reports are not copied into this public registry merely to satisfy
visibility.
